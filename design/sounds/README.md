# ㄅㄆㄇ小火車的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，四首曲子都是為這個 APP 新寫的。
聲音像一台玩具小火車：鈍鈍的、軟軟的，沒有刺耳或突然的聲音。

做的時候沒辦法用耳朵聽，是看數字（長度、音量、接頭）檢查的；請在手機上聽聽看，覺得哪個不像、不好聽再改。

## 怎麼產生
```
python3 design/sounds/make_sounds.py                    # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py whistle clack      # 只重做這幾個
python3 design/sounds/make_sounds.py preview 試聽.m4a     # 全部連在一起的試聽檔（要 ffmpeg）
```
- 亂數用固定的種子（照聲音的名字），每次跑出來的檔案都一模一樣。
- 程式會檢查：音效不超過 1.5 秒、不會太大聲、背景音樂 18～30 秒而且頭尾接得起來、資料夾裡沒有別的檔案、全部不超過 8 MB。
- 格式：WAV、單聲道、16 位元；背景音樂 16,000 Hz，音效 22,050 Hz。

## 背景音樂
| 檔案 | 用在哪裡 | 聽起來 |
|---|---|---|
| `music_station` | 火車站（首頁）、認符號、聽聽找找、家裡找找 | 輕快的木琴，中間一段口琴，反拍有火車「噗噗」的節奏，C 大調，每分鐘 112 拍 |
| `music_write` | 寫寫看 | 安靜的鋼琴，F 大調，72 拍 |
| `music_rhyme` | 押韻接龍 | 有節拍的（大鼓和拍手），上面是馬林巴木琴，幫忙聽詞的節奏和押韻，G 大調，100 拍 |
| `music_rest` | 休息時間 | 很輕的鐘琴搖籃曲，56 拍 |

## 火車的聲音
| 檔案 | 什麼時候 | 聲音 |
|---|---|---|
| `whistle` | 點火車頭、車廂掛上、開到下一站 | 玩具火車「嗚—」：三根笛子一起吹，最後音一點點往下 |
| `puff` | 火車頭冒煙 | 煙囪「噗噗」兩下 |
| `clack` | 火車開動 | 輪子「喀噠喀噠」，鈍鈍的玩具聲 |
| `couple` | 車廂接上去 | 「喀」 |
| `chime` | 到站 | 車站的鈴「叮咚」 |

## 玩的時候
| 檔案 | 什麼時候 | 聲音 |
|---|---|---|
| `ding` | 點符號、點車廂 | 「叮」 |
| `right` | 答對 | 往上的一小段木琴 |
| `try` | 點錯（不扣分） | 柔柔的低音「咚」 |
| `star` | 寫寫看點到起點 | 小小的亮晶晶 |
| `stroke` | 描完一筆 | 兩個木琴音 |
| `done` | 一個符號描完 | 小小的號角（木琴加鐘琴） |
| `sticker` | 家裡找找貼貼紙 | 「啵」加兩個鐘琴音 |
| `tap`、`pop`、`whoosh` | 按鈕、換頁 | 輕輕的點、啵、咻 |
| `night` | 休息時間到 | 三個往下的鐘琴音 |
