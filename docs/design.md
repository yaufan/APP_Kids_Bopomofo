# 設計：ㄅㄆㄇ小火車

> 給 4～6 歲小朋友學注音符號的遊戲。2026-11-15 定案（見最後「已經決定的事」）。草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」「動物小餐廳」「小卡認天下」「想一想樂園」「眼尖尖大挑戰」「迷宮小冒險」「小小生活家」是同一個作者的兄弟 APP，同一套技術，畫風不同。程式的架構最接近字母寵物（描筆畫、判斷寫對）和小小生活家（Python 畫 SVG、ParentPass）。

## 一句話
小朋友開一列小火車環島：每一個注音符號是一節車廂，看一看、聽一聽、找一找、描一描，就把那節車廂掛上去；車廂越掛越長，火車就從台北一站一站開到高雄。目的是在上小學前，把 37 個符號的「長相」和「聲音」連起來，而且耳朵學會分辨聲音（押韻、開頭音），這才是一年級注音學得好的關鍵。

## 給誰
- **4～6 歲**，在台灣，國語為主，幼兒園中班到大班。
- 為什麼要做：信誼的調查說大約九成的小朋友上小學前就學過一些注音，一年級只教十週，教育部現在也讓幼兒園教注音。可是市面上的注音 APP 不是有廣告、就是簡體字或英文介面，評價也很少。研究說大班的「聲音敏感度」（聽得出押韻、聽得出開頭音）可以預測一年級的注音成績，而且玩押韻遊戲的效果會留著，所以這個 APP 不只認符號，一半的時間在練耳朵。
- 兩個難度：**小火車**（4～5 歲）和**大火車**（5～6 歲），差別在下面每個模組裡寫。
- 不連網、不定位、沒有廣告、沒有帳號、不要任何權限（和兄弟 APP 一樣）。

## 練什麼
- **認符號**：37 個符號（聲母 21 個、韻母 16 個），每個都有一個圖、一個詞、一段小動畫，看到符號想得起聲音。
- **聽聲音**：聽到一個詞，找出它的開頭（或尾巴）是哪個符號。
- **練耳朵（聲音敏感度）**：哪兩個詞押韻？哪個詞是ㄇ開頭？這是研究說最有用、效果會留著的部分。
- **拼音**（大火車）：聲母＋韻母拼成一個字，四聲是四面小旗子。
- **寫符號**：照筆順描，手指一碰就畫（字母寵物做過的引擎）。
- **帶回真實生活**：「找找家裡有什麼ㄅ開頭的東西」，和爸爸媽媽一起找。

## 符號的順序：常用的先教，難發的音最後
不照課本ㄅㄆㄇㄈ的順序，先教最常用、最早學會發的音，而且第二站就可以拼出「爸、媽」這些字。七站，每站一組：

| 站 | 車站 | 符號 | 為什麼 |
|---|---|---|---|
| 1 | 台北 | ㄚ ㄧ ㄨ ㄛ ㄜ | 最常用的五個韻母，嘴巴張開就有；之後每一站的拼音都要用到 |
| 2 | 桃園 | ㄅ ㄆ ㄇ ㄈ | 嘴唇的音，最早會發；爸爸、媽媽都在這裡 |
| 3 | 新竹 | ㄉ ㄊ ㄋ ㄌ | 舌尖的音，弟弟、兔子、牛奶、老鼠 |
| 4 | 台中 | ㄍ ㄎ ㄏ | 喉嚨的音，狗狗、恐龍、花 |
| 5 | 嘉義 | ㄞ ㄟ ㄠ ㄡ ㄢ ㄣ ㄤ ㄥ | 複韻母和鼻音韻母，押韻遊戲最好玩的一站（貓、狗、糖、燈） |
| 6 | 台南 | ㄐ ㄑ ㄒ ＋ ㄩ ㄝ | 雞、氣球、西瓜、魚 |
| 7 | 高雄 | ㄓ ㄔ ㄕ ㄖ ㄗ ㄘ ㄙ ＋ ㄦ | 捲舌音和平舌音最難，5～6 歲才分得清楚，放最後 |

- 小火車（4～5 歲）走 1～4 站就很夠；大火車（5～6 歲）走完七站。家長模式可以關掉某幾站，或直接跳到某一站。
- **課本順序**（家長模式的開關）：給已經在幼兒園照課本學的小朋友對照。一樣七站，符號照ㄅㄆㄇㄈ排：ㄅㄆㄇㄈ／ㄉㄊㄋㄌ／ㄍㄎㄏㄐㄑㄒ／ㄓㄔㄕㄖㄗㄘㄙ／ㄧㄨㄩㄚㄛㄜㄝ／ㄞㄟㄠㄡ／ㄢㄣㄤㄥㄦ。這個順序前四站沒有韻母，所以拼拼看要到第 5 站才能玩。
- 第 5 站以後的韻母，有些沒有「它開頭」的好詞，就用「它結尾」的詞（貓＝ㄇ＋ㄠ），APP 會念「貓，ㄇ、ㄠ、貓」，正好練押韻。

## 畫面和玩法
主角是一列玩具小火車，司機是小朋友自己選的小動物（小熊、小兔、小貓、小企鵝）：只選外表，不取名字，少一個要家長打字的步驟。

### 1. 火車站（首頁）
- 上面是**台灣地圖**，七個車站連成一條鐵路，火車停在目前這一站；走過的站有小旗子。
- 中間是**自己的火車**：火車頭＋已經掛上的車廂，每節車廂寫一個符號，可以左右滑著看。車廂會隨著站的顏色不一樣（台北站淡藍、桃園站粉紅……）。
- 下面六個大按鈕：**認符號、聽聽找找、拼拼看、寫寫看、押韻接龍、家裡找找**。拼拼看 0.2 才有，而且小火車難度不會出現。
- 還沒掛上的車廂是灰灰的輪廓，點了會說「先去認符號吧」。
- 點火車頭會「嘟嘟—」鳴笛，開一小段，煙囪冒煙；什麼都不做火車也會慢慢動（輪子轉、冒煙）。

### 2. 認符號
- 畫面中間一節大大的車廂，上面是符號（例如 ㄅ），車廂旁邊是圖（爸爸）。
- 點車廂：念「ㄅ（播），爸爸」，符號跳一下、圖放動畫。可以一直點。
- 下面一排是這一站的符號，點哪個換哪個；這一站全部點過一遍，車廂就「掛上去」（火車頭來接，喀噠一聲，鳴笛）。
- 大火車多一個**「ㄅ 的小故事」**：符號本身也會動（ㄅ的那個勾勾像爸爸的手臂彎起來），幫忙記形狀。

### 3. 聽聽找找
- 上面是一個喇叭和一張圖，APP 念詞：「媽媽」。
- 下面 2 節車廂（小火車）或 3 節（大火車）：ㄇ、ㄅ、ㄈ。點對了，那節車廂開走、圖上的媽媽上車；點錯只是輕輕晃一下、再念一次那個符號的詞：「這是ㄅ，爸爸的ㄅ」，不扣分。
- 大火車另外有「尾巴是什麼」：「貓—ㄇ、ㄠ」找 ㄠ。
- 每一站 10 題，出題從這一站和前面站的符號混著出。

### 4. 拼拼看（只有大火車，0.2）
- 兩節車廂：聲母車廂（ㄅ）＋韻母車廂（ㄚ）。小朋友把韻母車廂拖過去（或點它），兩節「喀噠」接起來，APP 念：「ㄅ—ㄚ—ㄅㄚ」，然後出現一張圖和一個字：爸。
- **四聲是四面小旗子**插在車廂上：一聲平平、二聲往上、三聲彎彎、四聲往下，輕聲是一個小點。先只用「這個詞剛好的聲調」給小朋友看和聽（爸＝四聲旗子），家長打開「換聲調」後，可以點旗子換：ㄅㄚ（八）、ㄅㄚˊ（拔）、ㄅㄚˇ（把）、ㄅㄚˋ（爸），每一個都有圖的才出現。
- 三拼（ㄒ＋ㄧ＋ㄚ＝蝦）和結合韻放到 0.3。
- 拼出來的字變成**乘客**上車：爸爸、媽媽、鴨子、魚……火車站就看得到他們坐在車廂裡，這是拼拼看的獎勵。

### 5. 寫寫看
照字母寵物的四個小關卡（看、點、描、自己寫），引擎直接拿來用，不同的地方：
- 符號的筆順照教育部《國語注音符號手冊》，做的時候寫成 `docs/bopomofo.md`，字形用 JSON（和字母寵物一樣用 Python 產生）。注音的筆畫比英文字母少（最多 4 筆），但是有勾、有彎（ㄅ、ㄋ、ㄌ、ㄞ），描的時候「小路」要畫得寬一點。
- 寫在一節車廂上：車廂是方方的格子，符號填滿它。
- 小火車只做到「描」就算完成；大火車要「自己寫」拿到 1 顆星。寫反（鏡像）不打叉，溫和地再示範一次，和字母寵物一樣。
- 手指一碰就畫（`Listener`），支援觸控筆，家長可以設左撇子。

### 6. 押韻接龍（練耳朵）
三種題目，都是「聽、看圖、點」，不用認字：
- **哪兩個押韻？**：三張圖（貓、包、魚），念一遍，點出尾巴一樣的兩個（貓、包）。答對時兩張圖的車廂接起來，念「貓—包，ㄠ！」
- **哪個是ㄇ開頭？**：三張圖（媽媽、飛機、兔子），點出ㄇ開頭的。小火車從這題開始（開頭音比押韻容易）。
- **接龍**（大火車）：給一張圖（狗），下面三張圖選一個尾巴一樣的接上去（球），接對了火車變長，可以一直接。
- 答對會說出「為什麼」：「貓和包，尾巴都是ㄠ」。答錯念出兩個詞再聽一次，不扣分。

### 7. 家裡找找（離開螢幕的任務）
- 每天第一次玩完一個模組，司機會給一張**任務卡**：「找找家裡有什麼ㄅ開頭的東西？」（旁邊畫幾個提示：杯子、筆、包包）。
- 這一頁故意沒有東西可以點，只有一個大大的「找到了！」按鈕（給家長或小朋友找完回來按），按了火車頭多一個小貼紙（找到的東西的圖案，選一個）。
- 每個符號有 3～5 個提示詞（都是家裡找得到的：杯子、筆、包包、襪子、湯匙、門、燈……），家長模式可以看今天的任務。
- 這也是「家長一起玩」的提示：任務卡上寫「和爸爸媽媽一起找」。

### 獎勵
- **車廂**：認完一站的符號，那幾節車廂掛上火車。沒有星星、沒有分數，火車變長就是結果。
- **乘客**：拼拼看拼出來的字會上車。
- **車站**：一站的四個模組都做過（認、聽、寫、押韻），火車鳴笛開到下一站，地圖上插旗子，路上有一段 5 秒的風景動畫（過山洞、過橋、看到海）。
- **火車頭貼紙**：家裡找找的任務。
- 沒有排名、沒有倒數、沒有扣分、沒有每日連續天數的處罰。

## 每次玩多久
- 家長設定，**預設 15 分鐘**（和兄弟 APP 一樣）。時間到了火車進站、司機下車休息，畫面變暗，APP 說：「火車休息囉，去找找家裡的ㄅ吧！」要家長解開或等一個小時。
- 每個模組一輪大約 2～3 分鐘，一次玩可以做完兩三個模組。

## 4～5 歲和 5～6 歲的差別（家長模式選，預設照年齡）
| | 小火車（4～5 歲） | 大火車（5～6 歲） |
|---|---|---|
| 站 | 建議 1～4 站 | 七站全部 |
| 聽聽找找 | 2 選 1，只問開頭 | 3 選 1，開頭和尾巴 |
| 拼拼看（0.2） | 不出現 | 出現，聲調先固定，家長可以開「換聲調」 |
| 寫寫看 | 描完就好 | 要自己寫 |
| 押韻接龍 | 先玩「哪個是ㄇ開頭」，再玩「哪兩個押韻」 | 三種都有，加接龍 |
| 說明 | 司機每一步都說 | 說一次，之後只在點錯時說 |

## 家長模式（要過家長關卡 ParentPass）
- 難度（小火車／大火車）、每次玩多久。
- 要哪幾站（勾選）、直接跳到哪一站。
- 符號順序：常用的先（預設，七站）／課本順序（ㄅㄆㄇㄈ）。
- 聲調旗子（0.2）：關／固定／可以換。
- 語音：試聽按鈕（因為手機內建的國語語音品質不一定，家長先聽過）、速度、要不要每個詞念兩次。
- 進度：37 個符號每個的狀態（還沒、認過、聽對 3 次、描過、自己寫過），用車廂顏色畫出來；今天玩了幾分鐘、做了哪些模組；押韻題答對的比例（這個數字家長看了有用，小朋友看不到）。
- 家裡找找：今天的任務、找到過哪些。
- 左撇子、音樂、音效開關。
- 以後的完整版購買只在這裡。

## 畫風：軟膠公仔風（草圖見 `docs/mockups/0_畫風選擇.png` 的 A）
像軟膠玩具公仔（Sonny Angel、Playmobil 那種）：圓滾滾、亮亮的，顏色飽滿簡單，每一塊上面有一個大大軟軟的反光、邊緣一圈深色，小火車就是一台玩具火車，司機是軟膠小動物。
- **為什麼適合學注音**：符號要清楚。白色的符號加深色邊印在顏色飽滿的車廂上，在手機小螢幕上一眼看得到；玩具的質感讓「收集車廂、掛上火車」很有實感，4～6 歲剛好是愛玩具公仔的年紀。
- **怎麼畫**（只用 flutter_svg 做得到的東西，**不用濾鏡**）：每塊形狀用一個由上到下的漸層填色（上面亮一點、下面暗一點），外面一圈 2～3 px 的深色邊；反光是兩個白色橢圓（一個大的半透明、一個小的全白），用裁切（clipPath）限制在形狀裡；下緣再加一個裁切過的半透明黑色橢圓，看起來圓圓的；影子是同一個形狀往右下移一點、淡淡的黑色。符號用字型（jf open 粉圓）白色字加深色描邊。
- **顏色**：每一站一個顏色（台北淡藍、桃園粉紅、新竹綠、台中黃、嘉義橘、台南紫、高雄青綠），火車頭是紅色。
- 和八個兄弟 APP 的畫風都不一樣（粗黑框貼紙、水彩繪本、黏土、寫實／色塊、三種卡通、等角小模型／孔版／蠟筆、羊毛氈／像素／果凍、立體書），也和另外幾個新 APP 的畫風不一樣（棉花糖雲朵、星光剪影、霓虹舞台）。只做這一種。
- 看過但沒有選的候選：第一輪的木頭玩具風、磁磚馬賽克風、夜光霓虹風，第二輪的糖霜餅乾風、色鉛筆手繪風。

## 聲音
- **火車**：嗚—鳴笛、喀噠喀噠的輪子（玩具的，鈍鈍的）、煙囪「噗噗」、車廂接上「喀」、鈴鐺。全部用 numpy 合成。
- **動作**：點符號「叮」、答對是一小段上行的木琴、答錯是柔柔的「咚」、車廂掛上去是「喀」的一聲。
- **背景音樂**：火車站是輕快的木琴和口琴小曲（有火車的節奏）；寫寫看是安靜的鋼琴；押韻接龍是有節拍的（幫助聽節奏和押韻）；休息是搖籃曲。
- **語音**：用手機內建的國語語音（flutter_tts），但是**不能直接念單獨一個符號**（Android 的國語語音念「ㄅ」不穩定，有時候念不出來、有時候念成別的）。做法：
  1. 每個符號對應一個**同音的國字**給語音念，就是老師念符號的方式（ㄅ 念「播」）：

     | ㄅ播 | ㄆ坡 | ㄇ摸 | ㄈ佛 | ㄉ得 | ㄊ特 | ㄋ訥 | ㄌ勒 | ㄍ哥 | ㄎ科 | ㄏ喝 |
     |---|---|---|---|---|---|---|---|---|---|---|
     | ㄐ基 | ㄑ欺 | ㄒ希 | ㄓ知 | ㄔ吃 | ㄕ詩 | ㄖ日 | ㄗ資 | ㄘ雌 | ㄙ思 | |
     | ㄚ啊 | ㄛ喔 | ㄜ婀 | ㄝ耶 | ㄞ哀 | ㄟ欸 | ㄠ凹 | ㄡ歐 | ㄢ安 | ㄣ恩 | ㄤ骯 |
     | ㄥ（待測） | ㄦ兒 | ㄧ衣 | ㄨ烏 | ㄩ迂 | | | | | | |

     這張表放在程式裡（`core/voice.dart`），**念的時候永遠送國字，不送符號**。ㄥ 單獨沒有常用的國字，先試幾個（鞥、「嗯」的鼻音），不行就只念詞。
  2. 每次念符號都接著念詞：「播，爸爸」，小朋友聽到的重點是詞。
  3. 拼音念「ㄅ—ㄚ—ㄅㄚ」：送「播、啊、爸」三個國字，中間停一下。拼出來的字一定是表裡有圖的字，所以都有國字可以送。
  4. 0.1 的第一件事就是在使用者的手機上把這張表念一遍，用耳朵聽（家長模式的「試聽」按鈕也是為了這個）。念不好的字換一個同音字；試聽完再決定要不要用 numpy 合成簡單的母音（ㄚㄛㄜㄧㄨㄩ 這些母音可以合成，聲母不行）。
  5. 不錄音：錄音要麥克風權限，兄弟 APP 的規矩是不要任何權限。

## 和字母寵物不一樣的地方（寫程式時要注意）
- 注音的「聲音」比「寫」重要：一年級考的是聽寫和拼讀，所以認、聽、押韻排在寫前面；字母寵物是寫為主。
- 符號不能單獨用語音念（上面的「語音」），字母寵物的英文字母可以。
- 四聲：字母沒有，注音有；0.1 先不碰，0.2 用旗子。
- 筆順有勾和彎，小路要寬；符號最多 4 筆，比字母好描。
- 沒有寵物、沒有照顧；獎勵是火車變長。小朋友 4～6 歲，比字母寵物的 3 歲起稍大，可以多一點「想一想」的題目。
